# 最早披露日ROE与20日IC

现行参考使用主要会计数据表中的摊薄ROE。首先从定期财报记录确定每家公司、
每个报告期对应定期报告的最早披露时间，再选择该次披露对应的合并口径指标；
年报与次年一季报同日披露时，年末ROE仍取年报记录。不以随后出现的合并记录或
更正值重新定义首次披露。首次记录缺ROE时排除，不回填后续值。

收益从首次披露后的首个A股市场交易日收盘算起，结束于其后第20个市场交易日收盘。
ST状态在起始日判断。只要求这两个价格端点齐全，Spearman相关使用并列值的平均秩。

当前数据库保留记录上的首次取值逻辑、样本、收益和IC已验证。尚无独立的原始公告
或供应商版本档案证明所有首发值从未被覆盖；隔离重放成功不等于历史档案认证。
参考CSV按题面要求将IC保留四位小数。
